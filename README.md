# Encrypter-Decrypter-Script
This is a python script that can encrypt files and decrypt files.



How to use? ✨

Open the script and then you will see three options. One is "Encrypt." The second one is "Decrypt." The last one is "Exit."

There is a number next to each option. So, enter the option (number) you want in the command prompt.
